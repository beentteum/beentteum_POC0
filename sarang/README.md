## 두 수의 곱

### 문제 설명

두 정수 `num1`, `num2`가 주어질 때 두 수의 곱을 반환한다.

### Requirements

- 두 개의 정수를 입력받는다.
- 입력받은 두 수를 곱한다.
- 계산된 결과를 반환한다.

### 입력값

- `num1`: 첫 번째 정수
- `num2`: 두 번째 정수

### 출력값

- `num1 * num2`의 결과

### 풀이 Flow

`num1`, `num2` 입력

↓

두 값을 곱함

↓

결과 반환

### Business Logic

1. `num1`과 `num2`를 입력받는다.
2. `num1 * num2`를 계산한다.
3. 계산 결과를 반환한다.

### Code

```python
def solution(num1, num2):
    return num1 * num2
```

### Test Case

```python
print(solution(3, 4))
```

실행 결과:

```text
12
```

### 핵심 포인트

입력값 두 개를 함수의 매개변수로 받아 연산한 뒤, 계산 결과를 반환하는 기본적인 함수 구조를 이해하였다.

# 1. PoC 기능 개발

## 카페 즐겨찾기 등록

## 1. Requirements

사용자가 관심 있는 카페를 즐겨찾기에 등록할 수 있다.

### 요구사항

- 사용자는 카페 상세 페이지에서 즐겨찾기를 등록할 수 있다.
- 즐겨찾기 등록을 위해 사용자 정보와 카페 정보가 필요하다.
- 존재하지 않는 사용자는 즐겨찾기를 등록할 수 없다.
- 존재하지 않는 카페는 즐겨찾기를 등록할 수 없다.
- 이미 즐겨찾기에 등록된 카페는 중복 등록하지 않는다.
- 정상적으로 등록되면 즐겨찾기 등록 성공 결과를 반환한다.

### 입력값

- `userId`: 즐겨찾기를 등록하는 사용자 ID
- `cafeId`: 즐겨찾기에 등록할 카페 ID

### 결과

정상 등록:

```text
즐겨찾기 등록 완료
```

이미 등록된 카페:

```text
이미 즐겨찾기에 등록된 카페입니다.
```

사용자 또는 카페가 존재하지 않는 경우:

```text
등록 실패
```

## 2. User Flow

사용자가 카페 상세 페이지 접속

↓

즐겨찾기 버튼 클릭

↓

사용자 정보 확인

↓

사용자가 존재하는가?

- 아니오 → 등록 실패
- 예 → 카페 정보 확인

↓

카페가 존재하는가?

- 아니오 → 등록 실패
- 예 → 기존 즐겨찾기 확인

↓

이미 등록되어 있는가?

- 예 → `이미 즐겨찾기에 등록된 카페입니다.`
- 아니오 → 즐겨찾기 등록

↓

`즐겨찾기 등록 완료` 반환

### Exception

- 존재하지 않는 `userId` → 즐겨찾기 등록 실패
- 존재하지 않는 `cafeId` → 즐겨찾기 등록 실패
- 이미 등록된 `userId + cafeId` 조합 → 새로운 데이터를 생성하지 않음

## 3. Business Logic

1. `userId`와 `cafeId`를 입력받는다.
2. `userId`에 해당하는 사용자가 존재하는지 확인한다.
3. 사용자가 존재하지 않으면 실패 결과를 반환한다.
4. `cafeId`에 해당하는 카페가 존재하는지 확인한다.
5. 카페가 존재하지 않으면 실패 결과를 반환한다.
6. 해당 사용자가 카페를 이미 즐겨찾기에 등록했는지 확인한다.
7. 이미 등록되어 있다면 새로운 즐겨찾기 데이터를 생성하지 않는다.
8. 등록되어 있지 않다면 새로운 즐겨찾기 데이터를 생성한다.
9. 등록이 완료되면 `즐겨찾기 등록 완료`를 반환한다.

### 로직 요약

```text
userId, cafeId 입력
        ↓
사용자 존재 확인
        ↓
존재하지 않음 → 등록 실패
        ↓ 존재함
카페 존재 확인
        ↓
존재하지 않음 → 등록 실패
        ↓ 존재함
즐겨찾기 중복 확인
        ↓
중복 → 등록하지 않음
중복 아님 → 즐겨찾기 등록
```
